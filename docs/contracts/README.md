## 1. Conventions

**Versioning.** New JSON bodies carry `"contract": "opendevin.<name>/m0.1"`. Within `m0.x`,
producers may add fields; consumers ignore unknown fields. Adding an enum value bumps the
minor version and consumers must render an unknown enum value as a neutral "unknown" state,
never as success. Removing/renaming a field needs a coordinator decision + consumer task.

**IDs.** Opaque, `^[a-z]{2,4}_[0-9a-f]{24}$`, generated by `new_id(prefix)` =
`f"{prefix}_{secrets.token_hex(12)}"`. Prefixes in M0: `job`, `sec`. Clients never parse IDs.
Repository identity in M0 remains the legacy repo `name` (`^[A-Za-z0-9_.-]{1,64}$`) plus
`revision`; GitHub numeric identity is M1 (not a new field here).

**Timestamps.** DB: INTEGER Unix milliseconds UTC. New API JSON: RFC 3339 UTC with
milliseconds, e.g. `"2026-11-13T15:20:00.000Z"` (`format_ts(ms) -> str`). Legacy fields
(`/api/repos[].indexed_at`) are unchanged.

**Error shape (new routes only).**

```json
{"error": "Human-readable, content-free message.", "code": "snake_case_code"}
```

`error` stays the key the current `app.js` `api()` helper reads, so new and legacy errors render
identically. Optional `"detail"` object may carry IDs/counts only — never source text,
questions, payloads, paths or secret values. Legacy routes keep their exact `{"error": ...}`
bodies (no `code` added in M0).

In M0, host-check (403) and unknown-route (404) responses come from the shared legacy
dispatcher for every path and keep their legacy bodies; `forbidden_host`/`not_found` codes are
reserved for routes added after M0.

| `code` | HTTP | Meaning |
| --- | --- | --- |
| `forbidden_host` | 403 | Reserved: Host/Origin check failed |
| `not_found` | 404 | Reserved for routes with IDs; Python `NotFound` |
| `bad_request` | 400 | Validation failure |
| `unsupported_media_type` | 415 | Non-JSON body (future POST routes) |
| `conflict` | 409 | State/revision conflict |
| `idempotency_conflict` | 409 | Same key, different request |
| `not_configured` | 409 | Feature needs setup (e.g., no model) |
| `secret_store_unavailable` | 503 | No secure backend; setup blocked (OP-04) |
| `storage_busy` | 503 | SQLite busy after bounded retry |
| `internal` | 500 | Unexpected; message generic |

## 2. Platform Python interface

Package `repoask/platform/` (M0-PLATFORM exclusive). Standard library only. Python ≥3.11.
All public functions are synchronous and thread-safe through `Store`'s lock.

```python
# repoask/platform/__init__.py  — re-exports the names below
CONTRACT = "opendevin.m0/1"

# repoask/platform/clock.py
def now_ms() -> int: ...                       # int(time.time() * 1000)
def format_ts(ms: int | None) -> str | None: ...  # RFC 3339 'Z', millisecond precision
def new_id(prefix: str) -> str: ...            # see §1

# repoask/platform/errors.py
class PlatformError(Exception):
    code: str = "internal"                     # matches §1 table
class StorageBusy(PlatformError): code = "storage_busy"
class SchemaTooNew(PlatformError): code = "schema_too_new"          # DB version > code version
class MigrationChecksumMismatch(PlatformError): code = "migration_checksum_mismatch"
class MigrationFailed(PlatformError): code = "migration_failed"
class NotFound(PlatformError): code = "not_found"
class InvalidTransition(PlatformError): code = "conflict"
class IdempotencyConflict(PlatformError): code = "idempotency_conflict"
class LeaseLost(PlatformError): code = "lease_lost"
class SecretStoreUnavailable(PlatformError): code = "secret_store_unavailable"
class SecretRevoked(PlatformError): code = "secret_revoked"
class SecretMissing(PlatformError): code = "secret_missing"         # ref exists, backend lost value
# Exception messages never include payloads, secret values, source or absolute paths.

# repoask/platform/db.py
DB_FILENAME = "opendevin.sqlite3"
class Store:
    persistent: bool                           # False for ':memory:'
    @classmethod
    def open(cls, data_dir: Path | None, *, clock: Callable[[], int] = now_ms) -> "Store": ...
        # None -> ':memory:'. Else: mkdir(mode=0o700, parents=True, exist_ok=True); must be a dir;
        # file chmod 0o600; PRAGMAs foreign_keys=ON, busy_timeout=5000, journal_mode=WAL,
        # synchronous=FULL; isolation_level=None (explicit transactions); then apply_migrations().
    @contextmanager
    def transaction(self) -> Iterator[sqlite3.Connection]: ...  # lock; BEGIN IMMEDIATE; COMMIT / ROLLBACK
    @contextmanager
    def read(self) -> Iterator[sqlite3.Connection]: ...         # lock only, no write
    def schema_version(self) -> int: ...
    def size_bytes(self) -> int: ...           # page_count * page_size; 0 for memory
    def backup_to(self, target: Path) -> None: ...  # sqlite3 backup API, consistent snapshot
    def close(self) -> None: ...
# sqlite3.OperationalError 'database is locked' after busy_timeout -> StorageBusy.

# repoask/platform/platform.py
@dataclass
class Platform:
    store: Store
    jobs: "JobQueue"
    secrets: "SecretService"
    @classmethod
    def open(cls, data_dir: Path | None, *, secret_backend: "SecretBackend | None" = None,
             clock: Callable[[], int] = now_ms) -> "Platform": ...
        # secret_backend None -> UnavailableSecretStore(). Never selects a plaintext/memory store.
    def close(self) -> None: ...

# repoask/platform/workspace.py   (pure builders; coordinator wires routes)
def build_workspace_summary(index: "CodeIndex", model: "Ollama | None",
                            platform: Platform | None, *, now: int) -> dict: ...
def build_health(index: "CodeIndex", model: "Ollama | None",
                 platform: Platform | None, *, now: int) -> dict: ...
# Output exactly matches §6 and fixtures. Read-only: never mutates jobs, never calls Ollama,
# never touches the secret backend beyond status().
```

## 3. SQLite migrations

- Defined in `repoask/platform/migrations.py` as an append-only tuple:

```python
@dataclass(frozen=True)
class Migration:
    version: int                 # allocated by coordinator, contiguous from 1
    name: str                    # snake_case
    statements: tuple[str, ...]  # one SQL statement each; NOT executescript (it auto-COMMITs)
    @property
    def checksum(self) -> str: ...  # sha256 of '\n;\n'.join(statements)
MIGRATIONS: tuple[Migration, ...]
LATEST_VERSION: int              # MIGRATIONS[-1].version

def apply_migrations(conn: sqlite3.Connection, *, db_path: Path | None, clock) -> int: ...
```

- Runner creates `schema_migrations(version INTEGER PRIMARY KEY, name TEXT NOT NULL,
  checksum TEXT NOT NULL, applied_at INTEGER NOT NULL)` if missing (bootstrap, not a numbered migration).
- Startup order: (1) any recorded version > `LATEST_VERSION` → `SchemaTooNew`, refuse to start;
  (2) any recorded checksum ≠ code checksum → `MigrationChecksumMismatch`, refuse;
  (3) if pending migrations and the file DB already has applied versions, `backup_to(<data_dir>/backups/opendevin.pre-v{N}.sqlite3)` first;
  (4) each pending migration in its own `BEGIN IMMEDIATE` … insert `schema_migrations` row … `COMMIT`;
  any error → `ROLLBACK`, raise `MigrationFailed` (previous version stays intact).
- Also set `PRAGMA user_version = <version>` inside each migration transaction (diagnostic mirror only).
- Startup with `--data-dir` that fails to open/migrate exits non-zero with a content-free message.
  It never falls back to memory (fail closed).

**Migration registry (coordinator-owned allocation).**

| Version | Name | Owner card |
| --- | --- | --- |
| 1 | `foundation` | M0-PLATFORM |
| 2+ | unallocated — request from coordinator | — |

**Migration 0001 `foundation` (exact schema).**

```sql
CREATE TABLE jobs (
  id                 TEXT PRIMARY KEY,
  kind               TEXT NOT NULL CHECK (length(kind) BETWEEN 2 AND 64),
  state              TEXT NOT NULL CHECK (state IN
                       ('queued','leased','succeeded','failed','cancelled','needs_reconciliation')),
  effect             TEXT NOT NULL CHECK (effect IN ('safe','external')),
  priority           INTEGER NOT NULL DEFAULT 0,
  payload            TEXT NOT NULL,            -- canonical JSON object, <= 16384 bytes, no secrets
  idempotency_key    TEXT UNIQUE,
  attempts           INTEGER NOT NULL DEFAULT 0,
  max_attempts       INTEGER NOT NULL CHECK (max_attempts BETWEEN 1 AND 10),
  run_after          INTEGER NOT NULL,
  lease_owner        TEXT,
  lease_token        TEXT,
  lease_expires_at   INTEGER,
  cancel_requested   INTEGER NOT NULL DEFAULT 0 CHECK (cancel_requested IN (0,1)),
  checkpoint         TEXT,                     -- JSON object or NULL, <= 16384 bytes
  result             TEXT,                     -- JSON object or NULL, <= 16384 bytes
  last_error_code    TEXT,
  last_error_message TEXT CHECK (last_error_message IS NULL OR length(last_error_message) <= 500),
  created_at         INTEGER NOT NULL,
  updated_at         INTEGER NOT NULL,
  finished_at        INTEGER,
  CHECK ((state = 'leased') = (lease_token IS NOT NULL AND lease_owner IS NOT NULL
                               AND lease_expires_at IS NOT NULL))
);
CREATE INDEX jobs_claim ON jobs (state, run_after, priority);
CREATE INDEX jobs_lease ON jobs (state, lease_expires_at);
CREATE TABLE secret_refs (
  id          TEXT PRIMARY KEY,
  backend     TEXT NOT NULL,
  purpose     TEXT NOT NULL CHECK (purpose IN ('provider_api_key','github_app_private_key','github_token')),
  label       TEXT NOT NULL CHECK (length(label) BETWEEN 1 AND 100),
  created_at  INTEGER NOT NULL,
  revoked_at  INTEGER
);
```

No secret value, hash, fingerprint or prefix is stored in SQLite. No other tables in M0.

**Backup/restore (M0 documented path, OP-01).** Automatic pre-migration snapshot (above).
Manual: stop the app, copy `<data_dir>/opendevin.sqlite3` (WAL is checkpointed on clean close;
if `-wal`/`-shm` exist, copy them together). Restore: stop app, replace the file, start; the
runner's version/checksum checks validate it. Secrets are not in the DB and are never in backups.
A restore CLI is deferred.

## 4. Job queue

```python
# repoask/platform/jobs.py
JobState = Literal["queued","leased","succeeded","failed","cancelled","needs_reconciliation"]
TERMINAL = frozenset({"succeeded","failed","cancelled"})
DEFAULT_LEASE_MS = 30_000          # allowed 1_000..600_000
BACKOFF_BASE_MS, BACKOFF_CAP_MS = 2_000, 300_000

@dataclass(frozen=True)
class Job:
    id: str; kind: str; state: JobState; effect: Literal["safe","external"]; priority: int
    payload: dict; idempotency_key: str | None; attempts: int; max_attempts: int
    run_after: int; lease_owner: str | None; lease_expires_at: int | None
    cancel_requested: bool; checkpoint: dict | None; result: dict | None
    last_error_code: str | None; last_error_message: str | None
    created_at: int; updated_at: int; finished_at: int | None
    # lease_token is intentionally NOT a Job field.

@dataclass(frozen=True)
class Lease:
    job: Job; token: str; owner: str; expires_at: int      # repr hides token

@dataclass(frozen=True)
class HeartbeatResult:
    expires_at: int; cancel_requested: bool

class JobQueue:
    def __init__(self, store: Store, *, clock: Callable[[], int] = now_ms) -> None: ...
    def enqueue(self, kind: str, payload: Mapping[str, Any], *, effect: str = "safe",
                priority: int = 0, max_attempts: int = 3,
                idempotency_key: str | None = None, run_after: int | None = None) -> Job: ...
    def get(self, job_id: str) -> Job: ...                               # NotFound
    def claim(self, worker_id: str, *, kinds: Collection[str] | None = None,
              lease_ms: int = DEFAULT_LEASE_MS) -> Lease | None: ...
    def heartbeat(self, lease: Lease, *, checkpoint: Mapping[str, Any] | None = None,
                  lease_ms: int = DEFAULT_LEASE_MS) -> HeartbeatResult: ...   # LeaseLost
    def complete(self, lease: Lease, *, result: Mapping[str, Any] | None = None) -> Job: ...
    def fail(self, lease: Lease, *, code: str, message: str = "", retryable: bool) -> Job: ...
    def mark_unknown_outcome(self, lease: Lease, *, code: str, message: str = "") -> Job: ...
    def acknowledge_cancel(self, lease: Lease) -> Job: ...
    def cancel(self, job_id: str) -> Job: ...
    def reconcile_expired(self) -> list[str]: ...                       # affected job ids
    def resolve_reconciliation(self, job_id: str, *,
                               outcome: Literal["succeeded","failed","requeue"]) -> Job: ...
    def counts(self) -> dict[JobState, int]: ...                        # all six keys, zero-filled
    def recent_failures(self, *, limit: int = 5) -> list[dict]: ...     # {job_id, kind, code, at}

# repoask/platform/worker.py  (in-process, NOT started by the server in M0)
class RetryableError(Exception): code: str = "transient"
class PermanentError(Exception): code: str = "invalid_input"
class UnknownOutcomeError(Exception): code: str = "unknown_outcome"
Handler = Callable[[Job, "JobContext"], Mapping[str, Any] | None]
class JobContext:
    def checkpoint(self, data: Mapping[str, Any]) -> None: ...   # heartbeat with checkpoint
    @property
    def cancel_requested(self) -> bool: ...                       # refreshed by heartbeat
class Worker:
    def __init__(self, queue: JobQueue, handlers: Mapping[str, Handler], *, worker_id: str,
                 lease_ms: int = DEFAULT_LEASE_MS) -> None: ...
    def run_once(self) -> bool: ...   # claim one job of a registered kind; False if none
```

**Validation.** `kind` matches `^[a-z][a-z0-9_.]{1,63}$`. `payload`/`checkpoint`/`result`
must be JSON objects ≤16 KiB canonical (`json.dumps(sort_keys=True, separators=(",",":"))`);
otherwise `ValueError`. Payloads carry secret **ref IDs**, never values. `message` is truncated to 500 chars.
M0 registers **no production kinds**; tests use `test.*` kinds.

**Ownership rule.** A lease is valid iff the row has `state='leased'` and `lease_token = lease.token`.
`heartbeat/complete/fail/mark_unknown_outcome/acknowledge_cancel` with an invalid lease raise
`LeaseLost` and change nothing. A worker getting `LeaseLost` must stop the job without side effects.
Expiry alone does not invalidate a token; only reconciliation (which clears it) does.

**Transitions** (each one `BEGIN IMMEDIATE` transaction; `updated_at=now` always):

| From | Operation | Condition | To | Field effects |
| --- | --- | --- | --- | --- |
| — | `enqueue` | new key or no key | `queued` | `attempts=0`, `run_after=run_after or now` |
| any | `enqueue` | same key, same kind+canonical payload+effect | unchanged | returns existing job, no write |
| any | `enqueue` | same key, different request | unchanged | `IdempotencyConflict` |
| `queued` | `claim` | `run_after<=now`, kind filter; order `priority DESC, run_after, created_at, id` | `leased` | `attempts+=1`, new `lease_token`, `lease_owner`, `lease_expires_at=now+lease_ms` |
| `leased` | `heartbeat` | valid lease | `leased` | extend expiry; store checkpoint if given; return `cancel_requested` |
| `leased` | `complete` | valid lease | `succeeded` | `result`, clear lease, `finished_at` |
| `leased` | `fail` | `retryable` and `attempts<max_attempts` | `queued` | clear lease; `run_after=now+min(BASE*2**(attempts-1), CAP)`; error fields |
| `leased` | `fail` | otherwise | `failed` | clear lease; error fields; `finished_at` |
| `leased` | `mark_unknown_outcome` | valid lease | `needs_reconciliation` | clear lease; error fields |
| `leased` | `acknowledge_cancel` | valid lease and `cancel_requested` | `cancelled` | clear lease; `finished_at` (else `InvalidTransition`) |
| `queued` | `cancel` | — | `cancelled` | `finished_at` |
| `leased` | `cancel` | — | `leased` | `cancel_requested=1` (worker observes on heartbeat) |
| terminal | `cancel` | — | unchanged | idempotent, returns job |
| `needs_reconciliation` | `cancel` | — | unchanged | `InvalidTransition` (resolve first) |
| `leased` | `reconcile_expired` | `lease_expires_at<now`, `effect='external'` | `needs_reconciliation` | clear lease; `last_error_code='lease_expired'` |
| `leased` | `reconcile_expired` | expired, safe, `cancel_requested` | `cancelled` | clear lease; `finished_at` |
| `leased` | `reconcile_expired` | expired, safe, `attempts<max_attempts` | `queued` | clear lease; `run_after=now`; `last_error_code='lease_expired'` |
| `leased` | `reconcile_expired` | expired, safe, attempts exhausted | `failed` | clear lease; `last_error_code='lease_expired'`; `finished_at` |
| `needs_reconciliation` | `resolve_reconciliation` | `succeeded` / `failed` | that state | `finished_at` |
| `needs_reconciliation` | `resolve_reconciliation` | `requeue` | `queued` | `run_after=now`; attempts not reset |

"Clear lease" = `lease_owner=lease_token=lease_expires_at=NULL`. `claim()` runs
`reconcile_expired()` inside the same transaction before selecting. Restart does **not**
force-expire existing leases: a crashed process's leases expire after ≤`lease_ms` and are then
reconciled (safe with concurrent processes on one data dir; never infers success, OP-12).
Only the owning feature service (with external-state evidence) may call
`resolve_reconciliation`; M0 has no such caller.

Error codes written to `last_error_code`: `transient`, `rate_limited`, `timeout`, `auth`,
`invalid_input`, `unsupported`, `unknown_outcome`, `lease_expired`, `internal`.
`Worker.run_once` maps `RetryableError→fail(retryable=True)`, `PermanentError→fail(retryable=False)`,
`UnknownOutcomeError→mark_unknown_outcome`, any other exception → `fail(code="internal", retryable=False)`
with message = exception class name only (no `str(exc)`, which may contain content).

## 5. Secret store

```python
# repoask/platform/secrets.py
SecretPurpose = Literal["provider_api_key", "github_app_private_key", "github_token"]

@dataclass(frozen=True)
class BackendStatus:
    backend: str           # 'unavailable' in M0
    available: bool
    reason: str | None     # content-free setup guidance when unavailable

class SecretBackend(Protocol):
    name: str
    def status(self) -> BackendStatus: ...
    def put(self, ref_id: str, value: bytes) -> None: ...    # overwrite allowed
    def get(self, ref_id: str) -> bytes: ...                  # KeyError if absent
    def delete(self, ref_id: str) -> None: ...                # idempotent

class UnavailableSecretStore:                 # the ONLY runtime backend in M0
    name = "unavailable"
    # status() -> BackendStatus("unavailable", False,
    #     "No secure credential store is configured. Credential setup is disabled.")
    # put/get/delete -> raise SecretStoreUnavailable

@dataclass(frozen=True)
class SecretRef:
    id: str; backend: str; purpose: SecretPurpose; label: str
    created_at: int; revoked_at: int | None

class SecretValue:
    def __init__(self, value: str) -> None: ...
    def reveal(self) -> str: ...
    # __repr__/__str__ -> "SecretValue(***)"; not JSON-serializable (no __iter__/dict)

class SecretService:
    def __init__(self, store: Store, backend: SecretBackend, *, clock=now_ms) -> None: ...
    def status(self) -> BackendStatus: ...
    def create(self, purpose: SecretPurpose, label: str, value: str) -> SecretRef: ...
    def describe(self, ref_id: str) -> SecretRef: ...                 # NotFound
    def resolve(self, ref_id: str) -> SecretValue: ...
    def revoke(self, ref_id: str) -> SecretRef: ...
```

Fail-closed rules (tests must cover each):

1. `create` checks `backend.status().available` **before** any DB write; unavailable →
   `SecretStoreUnavailable`, zero rows written.
2. `create`: `BEGIN IMMEDIATE` → insert ref → `backend.put` → `COMMIT`. If `put` raises, `ROLLBACK`
   (no orphan ref). Empty `value` → `ValueError`.
3. `resolve`: `NotFound` if no ref; `SecretRevoked` if `revoked_at`; `SecretStoreUnavailable`
   if backend unavailable; `SecretMissing` if backend `KeyError` (requires reconnect, F12 acc. 4).
   There is no fallback to any other storage.
4. `revoke`: sets `revoked_at` (commit first, so access is blocked immediately), then
   `backend.delete` best-effort; repeat revoke is idempotent.
5. Values never appear in SQLite, exceptions, `repr`, logs, job payloads, health or summary.
6. The in-memory test double (`MemorySecretBackend`) lives under `tests/` only; no CLI flag,
   env var or `Platform.open` default can select it.

## 8. M0 slices and validation

**M0-PLATFORM (Codex)** — writes `repoask/platform/`, `tests/test_platform_*.py`.
Implements §2–§5 and the two builders in `workspace.py`. No `__main__.py`, no web, no network,
no live GitHub/model/execution, no production job kinds, no OS keychain.
Focused checks (behavior, not implementation mirroring):
1. Fresh file DB → version 1; reopen → no re-apply; records survive close/reopen.
2. Failing migration statement → `MigrationFailed`, previous version and rows intact; pre-migration backup exists.
3. DB with version > latest → `SchemaTooNew`; altered checksum → `MigrationChecksumMismatch`.
4. Idempotent enqueue returns same job; conflicting request raises.
5. Injected clock: safe job lease expiry → requeued after reconcile; attempts exhausted → failed;
   external job expiry → `needs_reconciliation` and **not** claimable.
6. Stale lease token after reconciliation → `LeaseLost` on complete/heartbeat, no state change.
7. Cancel queued/leased/terminal/needs_reconciliation per table; backoff values.
8. Secrets: unavailable backend → `create` raises with zero rows; with test double: put-failure rollback,
   revoke blocks resolve, missing value → `SecretMissing`; secret string absent from DB file bytes and reprs.
9. `build_workspace_summary`/`build_health` output equals fixtures' key sets for demo/no-platform and persistent cases.

**M0-EXPERIENCE (Claude)** — writes `repoask/web/`, `tests/ui/`. Consumes fixtures; no server edits.
Checks: existing Ask demo flow (examples, citations, source pane, picker) unchanged; nav + three views by
keyboard; legacy fallback; each fixture state renders distinct truthful text. Any automated UI test must
use no new dependencies; otherwise record a manual keyboard/screen-reader checklist in the handoff.

**M0-INTEGRATE (coordinator)** — writes `repoask/__main__.py`, `tests/test_repoask.py`.
Adds `--data-dir PATH` (optional; opt-in persistence), opens `Platform` at startup (fail closed on error),
`server.platform`, routes §6.2, `platform.close()` on shutdown. Adds HTTP tests: legacy shapes unchanged,
new routes match fixtures' key sets, host check on new routes, restart with `--data-dir` preserves a job.
Exit gate: `python3 -m unittest discover -s tests` passes; demo runs with no flags and writes no files.
